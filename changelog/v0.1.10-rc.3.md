## ProsaMD v0.1.10-rc.3

Релиз-кандидат цикла «Lossless core»: два точечных фикса по итогам ручного прогона rc.2.

**RU** — что нового относительно v0.1.10-rc.2:

- **Копирование всегда с markdown-разметкой** — «Копировать» и «Вырезать» из меню и панели правого клика в визуальном режиме кладут в буфер markdown (`**жирный**`, `[ссылка](адрес)`) — байт-в-байт как нативный Ctrl+C, как в Obsidian. Раньше эти команды несли чистый текст без форматирования (#47). Кодовый режим, как и прежде, отдаёт сырой markdown.
- **Заголовок окна показывает имя файла** — окно называется «имя — ProsaMD» (с точкой «• » при несохранённых изменениях); раньше имя не доезжало из-за отсутствующего разрешения Tauri (#43).

**EN** — what's new over v0.1.10-rc.2:

- **Copying always carries markdown** — "Copy" and "Cut" from the menu and the right-click panel in the visual mode now put markdown on the clipboard (`**bold**`, `[link](url)`) — byte-for-byte identical to the native Ctrl+C, like Obsidian. Previously those commands produced plain, formatting-free text (#47). The source mode keeps returning raw markdown as before.
- **The window title shows the file name** — the window is titled "name — ProsaMD" (with a "• " dot for unsaved changes); the name used to be lost due to a missing Tauri permission (#43).
