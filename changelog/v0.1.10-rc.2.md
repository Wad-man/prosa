## ProsaMD v0.1.10-rc.2

Релиз-кандидат цикла «Lossless core»: честная семантика таблиц, клавиатурная полировка диалогов.

**RU** — что нового относительно v0.1.10-rc.1:

- **Выравнивание таблиц больше не выдумывается** — колонка с разделителем `| - |` (без выравнивания) при сохранении из визуального режима больше не превращается в `| :- |`; явные `:--` / `:-:` / `--:` сохраняются на своих местах (#33). Компактная таблица `\| a \| b \|` / `\| - \| - \|` / `\| 1 \| 2 \|` теперь проходит цикл «открыл → правил → сохранил» байт-в-байт.
- **Маркеры списков и разделители сохраняются** — `- `-маркер больше не меняется на `*` при сохранении из визуального режима (соседний `* `-список тоже остаётся собой), а горизонтальная линия `---` не превращается в `***` (#33).
- **Стрелки переключают кнопки в диалогах** — как в родных окнах Windows: в диалоге несохранённых изменений, «О программе» и «Горячих клавишах» ←/→/↑/↓ двигают фокус по кнопкам циклически; Esc и Tab работают как раньше (#39).
- **Esc закрывает ввод ссылки** — если после `Ctrl+K` фокус остался в тексте, Escape всё равно закрывает панельку ссылки без вставки (#38).

**Документированные нормализации** визуального режима для отредактированного документа (косметика, данные не теряются; кодовый режим сохраняет побайтово): выравнивание ширины ячеек и дефисов разделителя по колонке; повторные пустые строки схлопываются в одну (включая строку сразу после закрывающего `---` front-matter, #40); маркер `+` нормализуется в `-`, как и отдельный `* `-список, не соседствующий с `- `-списком; между соседними списками с разными маркерами появляется пустая строка-разделитель.

**EN** — what's new over v0.1.10-rc.1:

- **Table alignment is no longer invented** — a column delimited with `| - |` (no alignment) no longer comes back from the visual mode as `| :- |`; explicit `:--` / `:-:` / `--:` stay where they were (#33). A compact `\| a \| b \|` / `\| - \| - \|` / `\| 1 \| 2 \|` table now survives open → edit → save byte-for-byte.
- **List markers and rules survive** — a `- ` bullet no longer flips to `*` on save from the visual mode (an adjacent `* ` list stays `* `), and a `---` horizontal rule no longer turns into `***` (#33).
- **Arrow keys move between dialog buttons** — like native Windows dialogs: in the unsaved-changes prompt, About and the keyboard-shortcuts window ←/→/↑/↓ cycle focus across the buttons; Esc and Tab behave as before (#39).
- **Escape closes the link input** — if focus stayed in the text after `Ctrl+K`, Escape still dismisses the link input without inserting anything (#38).

**Documented normalizations** of the visual mode for an edited document (cosmetic, no data loss; the source mode saves byte-for-byte): cell and delimiter dashes are padded to the column width; repeated blank lines collapse into one (including the line right after the closing `---` of front-matter, #40); a `+` marker normalizes to `-`, as does a standalone `* ` list not adjacent to a `- ` one; a separating blank line appears between adjacent lists with different markers.
