## ProsaMD v0.1.10-rc.1

Релиз-кандидат цикла «Lossless core»: сохранение «байт-в-байт», честные хоткеи и полировка старта.

**RU** — что нового относительно v0.1.9:

- **Front-matter больше не портится** — блок `--- … ---` (Jekyll, Hugo, Zettelkasten) невидим в визуальном режиме и возвращается в файл байт-в-байт; в кодовом режиме виден как обычно (#33).
- **Нетронутый документ сохраняется исходными байтами** — открыл → `Ctrl+S` → файл не изменился: без переформатирования таблиц и пустых строк (#33).
- **Полный откат снимает индикатор правок** — `Ctrl+Z` до исходного текста гасит точку в статусной строке и «• » в заголовке окна (#29).
- **Честная toggle-семантика блоков** — повторное применение цитаты/списка снимает его, `Ctrl+Alt+8` ↔ `Ctrl+Alt+7` конвертирует список на месте, `Ctrl+0` выводит блок из цитаты или списка — одинаково в обоих режимах (#28).
- **Хоткеи под мышечную память Word / Obsidian / Telegram**: зачёркивание `Ctrl+Shift+X`, инлайн-код `Ctrl+Shift+M`, маркированный список `Ctrl+Shift+L`, цитата `Ctrl+Shift+Q` и `Ctrl+Shift+.`, удалить строку `Ctrl+D`, флажок задачи `[x]` `Ctrl+L`, снять форматирование `Ctrl+Shift+N`, закрыть окно `Ctrl+W`. Прежние биндинги не изменились; полный список — Справка → «Горячие клавиши» (#35).
- **Старт без мигания** — окно появляется сразу с документом: ни белого кадра, ни пустой оболочки; пока файл в пути — тихий индикатор загрузки вместо вводящей в заблуждение подсказки (#34).
- **Оглавление раскрывается плавно** — анимация ширины ~0,2 с вместо резкого появления; мгновенно при включённой системной опции «уменьшить анимацию» (#36).
- **Точка несохранённых изменений подписана** — при наведении поясняет смысл, зона наведения шире самой точки (#31).
- **Стабильность долгих сессий** — устранён рост обработчиков событий при переключении режимов (~21 на каждое переключение раньше, ноль сейчас) (#30).

**Известное ограничение** (цель следующего RC, #33): сохранение из визуального режима отредактированного документа с GFM-таблицами всё ещё косметически переформатирует таблицы (разделитель `| - |` → `| :- |`, выравнивание ячеек) и нормализует пустые строки и маркеры списков; данные не теряются. Кодовый режим сохраняет файлы побайтово.

**EN** — what's new over v0.1.9:

- **Front-matter is no longer mangled** — the `--- … ---` block (Jekyll, Hugo, Zettelkasten) stays out of the visual editor's way and is re-attached to the file byte-for-byte; the source mode shows it as always (#33).
- **An untouched document saves its original bytes** — open → `Ctrl+S` → the file is unchanged: no table re-padding, no blank-line normalization (#33).
- **A full undo clears the dirty flag** — `Ctrl+Z` back to the original text hides the statusbar dot and the «• » window-title mark (#29).
- **Honest block toggling** — re-applying a quote or list removes it, `Ctrl+Alt+8` ↔ `Ctrl+Alt+7` converts the list type in place, `Ctrl+0` lifts a block out of a quote or list — identically in both modes (#28).
- **Shortcuts for Word / Obsidian / Telegram muscle memory**: strikethrough `Ctrl+Shift+X`, inline code `Ctrl+Shift+M`, bullet list `Ctrl+Shift+L`, quote `Ctrl+Shift+Q` and `Ctrl+Shift+.`, delete line `Ctrl+D`, task checkbox `[x]` `Ctrl+L`, clear formatting `Ctrl+Shift+N`, close window `Ctrl+W`. Existing bindings are unchanged; the full list is in Help → Keyboard Shortcuts (#35).
- **No startup flicker** — the window appears with the document already in it: no white frame, no empty shell; while the initial file is in flight a quiet loader replaces the misleading hint (#34).
- **The outline opens smoothly** — a ~0.2 s width animation instead of an abrupt show/hide; instant when the OS "reduce motion" option is on (#36).
- **The unsaved-changes dot explains itself** — a tooltip on hover, with a hover area wider than the 7 px dot (#31).
- **Long-session stability** — the event-listener growth on mode switches is gone (~21 per switch before, zero now) (#30).

**Known limitation** (next RC's goal, #33): saving an edited document with GFM tables from the visual mode still reformats table cosmetics (delimiter `| - |` → `| :- |`, cell padding) and normalizes blank lines and list markers; no data is lost. The source mode saves byte-for-byte.
