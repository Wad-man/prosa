**Минималистичный открытый редактор и читалка Markdown — «блокнот» для `.md`-файлов.**
A minimal open-source Markdown reader & editor — a "notepad" for `.md` files.

Сайт проекта — **[prosamd.ru](https://prosamd.ru)** · [Скачать последнюю версию](https://github.com/Wad-man/prosa/releases/latest)

Десктоп: Windows (x64 / ARM64), macOS (Intel / Apple Silicon), Linux — на Tauri 2.
В планах: iOS и Android (Tauri 2 mobile).

## Чем ProsaMD отличается

- **Как блокнот**: открыл файл → читаешь/редактируешь → сохранил. Никаких хранилищ, vault'ов и баз данных — только ваши `.md`-файлы на диске.
- **Ровно два режима** (переключение `Ctrl+/`):
  - **Визуальный** — Markdown рендерится на лету: весь документ сразу выглядит готовым. Показ исходного синтаксиса блока под курсором (как в Typora) — цель роадмапа;
  - **Код** — классический текстовый редактор с подсветкой Markdown и кода в блоках (CodeMirror 6).
- **Бесплатно и открыто** (MIT).

## Возможности v0.1.0

- Открытие/сохранение/«сохранить как», drag&drop `.md`-файла в окно
- Несколько файлов одновременно: каждый документ — в своём окне (повторное открытие уже открытого файла фокусирует его окно)
- Индикатор несохранённых изменений, счётчик слов и символов; при закрытии окна с правками — вопрос о сохранении
- Диалог «О программе» по клику на версию в статусной строке
- Светлая/тёмная тема (по умолчанию — как в системе)
- Интерфейс RU / EN (переключается кнопкой)
- Проверка и установка обновлений прямо из приложения
- GFM-таблицы, чек-листы, подсветка кода, формулы и диаграммы — из коробки визуального режима

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | Открыть файл |
| `Ctrl+S` / `Ctrl+Shift+S` | Сохранить / Сохранить как |
| `Ctrl+/` | Переключить режим Визуальный ⇄ Код |
| `ПКМ` | Панель форматирования: с выделением — жирный/курсив/код/ссылка, с курсором в блоке — смена типа блока |
| `Ctrl+1`…`Ctrl+6` / `Ctrl+0` | Заголовок 1–6 / обычный текст (то же: `Ctrl+Alt+1…6`, `Ctrl+Alt+0`) |
| `Ctrl+Alt+7` / `Ctrl+Alt+8` | Нумерованный / маркированный список |
| `Ctrl+Alt+C` / `Ctrl+Shift+B` | Код-блок / цитата |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | Жирный / курсив / инлайн-код |

В визуальном режиме также работают markdown-сокращения при вводе: `# ` — заголовок, `- ` — список, `> ` — цитата, ``` — код-блок, `**жирный**`, `*курсив*`; `/` в начале пустой строки открывает меню вставки блоков.

## Сборка из исходников

Требования: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) (stable, MSVC на Windows), на Windows — VS Build Tools с workload «C++».

```bash
npm install
npm run tauri dev      # запуск в dev-режиме
npm run tauri build    # release-сборка (Windows: exe + NSIS-установщик)
```

Готовые сборки — в [релизах этого репозитория](https://github.com/Wad-man/prosa/releases).

## Обновления

ProsaMD проверяет обновления при запуске (тихо, в фоне). Ручная проверка — в
диалоге «О программе» (клик по версии в правом нижнем углу статусной строки).
Установка — скачивание пакета, проверка
подписи и перезапуск; права администратора не нужны (установка per-user).
У «portable»-сборки (голый `exe` без установщика) автообновления нет — новую
версию нужно скачать вручную.

Релизы и их подписи публикуются в [релизах этого репозитория](https://github.com/Wad-man/prosa/releases)
(до открытия исходников — в отдельном репозитории
[Wad-man/prosa-releases](https://github.com/Wad-man/prosa-releases), теперь архивном).

## Архитектура

```
Ядро (TypeScript, общий код для всех платформ)
├─ Визуальный режим — Milkdown (Crepe) на ProseMirror + remark
├─ Кодовый режим    — CodeMirror 6
└─ Нативная оболочка — Tauri 2 (Rust): файлы, диалоги, окна
```
