# ProsaMD — логотип, краткое руководство

**Идея знака:** буква P, ножка которой заточена в остриё пера. P — Prosa, остриё ↓ — MD (стрелка из классического знака Markdown). Одна форма — и название, и суть продукта: здесь пишут и читают.

## Версии

| Файл | Где использовать |
|---|---|
| `prosamd-horizontal.svg` | основная: шапка сайта, README, окно «О программе» |
| `prosamd-stacked.svg` | квадратные и узкие форматы: стартовый экран, наклейка, обложка |
| `prosamd-symbol.svg` | знак отдельно: аватар, иконка, водяной знак — от 24 px |
| `prosamd-symbol-small.svg` | 16–24 px: favicon, трей, вкладки (шире просвет, толще ножка) |
| `*-black` / `*-white` / `*-ink` | одноцветная печать, гравировка, тёмный фон |
| `icons/` | favicon.ico, favicon.svg, PNG 16/32/48/180/192/512, maskable, `site.webmanifest`, `head-snippet.html`, иконка приложения 512/1024 |
| `png/` | растровые локапы 1200 px на прозрачном фоне |

## Цвет

| | HEX | RGB | CMYK (ориентир) | Pantone (ориентир) |
|---|---|---|---|---|
| **Киноварь** — знак, «MD» | `#D9452B` | 217 69 43 | 0 68 80 15 | ≈ 7417 C |
| **Чернила** — «Prosa», текст | `#1D1B26` | 29 27 38 | 24 29 0 85 | ≈ Black 6 C |
| Бумага — фон | `#FFFFFF` | 255 255 255 | 0 0 0 0 | — |

CMYK и Pantone — расчётные; перед печатью сверить по вееру. Контраст киновари к белому — 4,35:1 (достаточно для знака и крупного текста, но не для мелкого текста интерфейса — для него используйте «Чернила», 17:1).

## Охранное поле и минимальный размер

- Охранное поле = **ширина ножки P** (≈ 16 % высоты знака) со всех сторон. Внутрь поля не заходят текст, края кадра, другие знаки.
- Минимум: горизонтальный локап — **96 px / 20 мм** по ширине; знак — **24 px / 6 мм**; ниже — только `prosamd-symbol-small.svg` (до 16 px).

## Шрифт

Вордмарк — **Noto Sans Bold** (лицензия SIL OFL, разрешает использование в логотипе), переведён в кривые, трекинг −2. «Prosa» — чернила, «MD» — киноварь. Для текстов вокруг логотипа подходит тот же Noto Sans (Regular/Bold).

## Фоны

- ✅ Белый, светло-серый, бумага — цветная версия.
- ✅ Киноварь — белый знак (как иконка приложения).
- ✅ Чёрный / тёмная тема — белая версия (`*-white`) или знак киноварью.
- ✅ Фото — только на спокойном участке, белая версия.

## Нельзя

- Перекрашивать знак в другие цвета, добавлять градиенты, тени, обводки.
- Растягивать, наклонять, поворачивать (повёрнутый на 180° знак читается как «d», зеркальный — как «q»).
- Менять пропорции и расстояние между знаком и словом, набирать «ProsaMD» другим шрифтом рядом со знаком.
- Скруглять остриё или убирать его — без острия знак становится просто буквой P.
- Ставить цветной знак на пёстрый фон или фон близкого тона (оранжевый, красный).

## Мастер-файлы и пересборка

Все SVG — чистые контуры без `<text>`, растров и фильтров. Пересобрать после правок геометрии или цвета: `python ../build_kit.py` (из папки `md-notebook-logo`), затем экспорт иконок скриптом `export_variants.py` навыка logo-design.

## Открытые пункты

- Регистрационная проверка товарного знака и обратный поиск по изображению (дальнее родство: Pinterest, значки-булавки на картах).
- Иконки ОС: `.icns` для macOS, `.ico` для Windows-установщика (можно взять `icons/favicon.ico` как основу, но для установщика нужны 256 px), PNG-набор для Linux (hicolor).
- README-баннер и соцкарточка 1280×640 для GitHub.
